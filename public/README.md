# Lewis Carroll: A Distant Reading

An interactive web visualization exploring four works by Lewis Carroll through computational text analysis.

## About

This project performs distant reading analysis on four Lewis Carroll works:
- **Alice's Adventures in Wonderland**
- **Phantasmagoria and Other Poems**
- **Rhyme? and Reason?**
- **Feeding the Mind**

The analysis includes:
- Word frequency analysis (bag of words)
- Sentiment analysis (polarity and subjectivity)
- Style metrics (sentence length, vocabulary richness, etc.)
- Interactive word clouds
- Comparative analysis across works

## Viewing the Visualization

### Option 1: Simple HTTP Server (Python)
```bash
# From the public/ directory
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

### Option 2: Simple HTTP Server (Node.js)
```bash
# Install http-server globally
npm install -g http-server

# From the public/ directory
http-server -p 8000
```
Then open `http://localhost:8000` in your browser.

### Option 3: VS Code Live Server
If using VS Code, install the "Live Server" extension and right-click on `index.html` to open with Live Server.

## Features

### Overview Tab
- View detailed statistics for each book
- See sentiment analysis with visual bars
- Explore the 30 most frequent words

### Word Cloud Tab
- Interactive word cloud visualization
- Word size represents frequency
- Victorian color scheme

### Compare Tab
- Select multiple books to compare
- Side-by-side metrics comparison
- Sentiment comparison

## Design

The interface features a Victorian/Alice in Wonderland aesthetic with:
- Vintage color palette (burgundy, forest green, gold)
- Playing card suit symbols (♠ ♥ ♣ ♦)
- Classic serif typography (Garamond)
- Whimsical, old-timey styling

## Data

All analysis data is stored in `data/analysis.json`, generated by the Python analysis scripts in the `analysis/` directory.

## Re-running Analysis

To regenerate the analysis data:
```bash
cd ../analysis
python3 analyze.py
```

This will process the text files and update `public/data/analysis.json`.
